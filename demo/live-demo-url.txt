NOT DEPLOYED — run locally using docs/setup-guide.md

The application runs entirely on a local Flask development server.
A judge can have it fully operational in under 2 minutes:

  cd bob-ai-hackathon-Team/src
  pip install -r requirements.txt
  python app.py

Then open http://localhost:5000 in any modern browser.
Click "Run Pre-loaded Sample Day" to populate the entire dashboard instantly
without needing any CSV file or API key.
